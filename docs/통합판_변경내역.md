# 준비물·정비 원칙 통합 교육판

2026-10-18 제작.

## 바뀐 내용

- 30개 본책의 첫장 부품 사진·작업 소개를 보존하고, 다음 한 쪽 작업 길잡이에 공구·보호 준비물, 교환 부품·조건, 작업 전 정비 원칙, 완료 확인을 통합했다.
- 작업 길잡이에는 핵심 요약과 실제 근거 쪽번호를 표시하고, 종합 색인 뒤의 해당 책자 상세 목록으로 연결한다. 상세 목록에는 본절차와 삽입 참조절차의 자료를 함께 집계한다.
- 상세 목록에 공구의 용도·적용 범위, 특수공구 번호, 교환의 필수·조건부 기준, 원문 파일·쪽, 본책 내 해당 쪽을 표시한다.
- 원문의 참고 상자 안에 있는 필수 지시도 별도 필수 표식으로 보조한다. 본문 상단의 표식은 원문 내용을 가리키며 지시나 수치를 대체하지 않는다.
- 참조 1~5차의 선·점선 체계, 참조 즉시 삽입·복귀, 양면 제본 여백과 바깥쪽 하단 쪽번호를 유지한다.

## 결과물 구성

- 본책 30개: 기존과 같은 1,006쪽.
- 종합 색인 3개: 기존 색인 86쪽을 보존하고 준비물·정비 원칙 상세 66쪽을 추가해 152쪽.
- 총 PDF 33개·1,158쪽.
- 압축파일 3개: 전체, 프런트 도어, 리어 도어. 각 압축파일에 필요한 종합 색인이 포함된다.

## 근거와 한계

- 공구·부품 데이터는 원본 94쪽의 공구·준비물 166행과 교환 부품·조건 41행을 시각 대조했다.
- 정비 원칙 데이터는 원본 73쪽의 원칙 171건·완료 확인 18건을 시각 대조했다. 공통 정비 원칙 8건은 별도로 기록한다.
- 두 자료를 합친 확인 원문은 113쪽이다. 미검증 OCR 신호는 새 요약으로 표시하지 않는다. 모든 원문 페이지 자체는 기존과 같이 보존한다.
- 차량용 주문 품번·수량은 확인되지 않아 추정하지 않았다. 특수공구 번호는 차량 부품번호와 구별한다. 적용 품번은 차대번호와 부품 카탈로그 대조가 필요하다.
- 고전압 지시는 해당 원문 범위에만 적용한다. 대기시간·전압·토크 같은 수치는 요약에서 다시 만들지 않고 원문에 보존한다.
- 부분으로 나뉜 원문은 요약문별 실제 원문 좌표를 대조해 해당 문장이 포함된 조각으로만 연결한다. 정비 원칙·완료 확인 189개 중 부분 삽입에서 쓰이는 91개의 위치를 별도 매핑했고, 나머지 98개는 전체 원문 쪽의 범위를 사용한다.
- 빈 분류는 한 줄 상태로 표시해 불필요한 계속면을 줄였고, 숫자와 특수공구 번호는 단어 중간에서 줄바꿈하지 않는다.
