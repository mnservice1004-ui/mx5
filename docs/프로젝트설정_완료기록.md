## 다음 편집과 구분할 사항

이번에 재제작한 시안은 실행 환경을 확인하기 위한 기존 교육판 재현이다. 공구·교환 부품 요약표나 정비 원칙 강조를 추가한 새 판본은 아니다. 해당 개선 사항은 `다음작업.md`에 기록했다.

현재 전체 검증기는 기존 판본의 쪽수·링크 수 등도 확인한다. 다음 편집으로 페이지나 안내 링크를 늘리는 경우에는 새 구조를 검증할 기준값도 근거에 맞게 함께 갱신해야 한다.

초기 프로젝트 설정 당시에는 Git 커밋과 원격 업로드를 수행하지 않았다. 이후 2026-10-18 사용자가 작업 완료 시 커밋·push를 항상 수행하도록 지시하여 `AGENTS.md`와 프로젝트 안내에 반영했다. 실제 커밋과 원격 반영 여부는 Git 이력과 원격 브랜치를 기준으로 확인한다.

## VS Code 열기 확인

프로젝트 workspace 파일을 VS Code 새 창으로 여는 명령을 실행했다. 이어서 VS Code의 `--status`가 반환한 Workspace Stats에서 `싼타페mx5 정비메뉴얼` 폴더와 `settings.json`, `tasks.json`, `project.json` 인식을 확인했다. VS Code 메뉴의 작업 버튼을 직접 눌러 검증한 것은 아니며, 위 제작·검증은 등록된 작업과 동일한 진입 명령을 터미널에서 실행한 결과다.
