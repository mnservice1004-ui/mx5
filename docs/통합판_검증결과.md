주 검토자는 별도로 첫장·밀집 길잡이·분할 원문·1~5차 참조·4차에서 3차로 복귀·미수록 원문 안내의 실제 이미지를 열어 확인했다. 분할된 원문 1.pdf 3쪽의 금속 제거·보호 장비 지시는 01책 5쪽, 고전압 차단 지시는 9쪽으로 연결되는 것을 대조했다.

모든 페이지를 사람이 한 줄씩 재독하거나 모든 링크를 PDF 뷰어에서 직접 클릭한 것은 아니다. 실물 출력·제본이나 실제 정비 수행 검증은 하지 않았다. 자동 검사와 실제 이미지 검토의 범위는 구별하여 기록했다.

## 미확인 사항

차량용 주문 품번·수량은 원문에서 확인되지 않아 추정하지 않았다. 특수공구 번호와 차량 부품번호는 구분했다. 원본 압축파일에 없는 참조절차는 기존의 미수록 안내와 종합 색인 연결을 유지했다. 새 요약에는 시각 대조를 끝낸 원문 113쪽의 근거만 사용하며, 검증하지 않은 OCR 신호로 내용을 채우지 않았다.

## 실행 기록

- `reports/draft_edition_qa.json`: 구조·원문·참조·복귀·색인·ZIP.
- `reports/service_content_qa.json`: 근거·적용 범위·분할 원문 좌표.

- `reports/service_final_review.json`: 최종 출력물 해시와 위 검토 기록의 일치.
- `reports/release_upload.json`: 실행 후 기록되는 GitHub 비공개 초안 릴리스의 압축파일 원격 SHA-256.

생성 PDF·ZIP·렌더 이미지는 Git 이력에 넣지 않는다. 제작 코드·근거 데이터·기준 문서는 작업 브랜치에 커밋·push하고, 압축파일은 게시하지 않은 초안 릴리스에 별도 보관한다.
